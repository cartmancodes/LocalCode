# Superseded Python TUI prototype

Archived during the 2026-10-02 review after the decision to implement a Rust-only
terminal application. These files are incomplete design work, not supported
application code or executable acceptance tests. Their original relative paths
are retained with a `.txt` suffix so tooling treats them as archival text. The frozen-worker patch is preserved separately because its
entrypoint and packaging were never implemented. Do not install this prototype.

The active design is [Rust harness v3](../../superpowers/specs/2026-09-30-rust-harness-v3-design.md).
Existing Python CLI/RPC behavior remains available during migration. The active Rust preview includes a terminal UI; see [its current scope](../../tui.md).
Full feature parity remains pending.
